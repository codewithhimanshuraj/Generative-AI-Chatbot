# 🤖 Generative AI Chatbot

A beginner-friendly **Generative AI project** built to explore LLMs, chat models, embeddings, and AI-powered applications using Python.

This repository contains multiple experiments and implementations focused on understanding how modern Generative AI systems work.

## 🚀 Features

* 💬 Chat with AI using Large Language Models
* 🧠 Experiment with different chat models
* 🔤 Explore text embeddings
* 🎬 **CineSage** — an AI-powered movie-related application
* 🔐 Environment variable support for API keys
* 🐍 Python-based Generative AI implementations

## 🛠️ Tech Stack

* **Python**
* **LangChain**
* **LLMs / Chat Models**
* **Embeddings**
* **Generative AI APIs**
* **python-dotenv**
* **UV / Python virtual environment**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/codewithhimanshuraj/Generative-AI-Chatbot.git
```

### 2. Navigate to the project

```bash
cd Generative-AI-Chatbot
```

### 3. Create a virtual environment

Using Python:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

## 🔑 Environment Variables

Create a `.env` file in the required project directory and add your API keys:

```env
GROQ_API_KEY=your_api_key
GOOGLE_API_KEY=your_api_key
```

Only add the keys required by the specific model/application you are running.

> ⚠️ Never commit your `.env` file or expose your API keys publicly.

## ▶️ Run the Project

After installing the dependencies and configuring your environment variables, run the Python files inside the respective project folders.

For example:

```bash
python filename.py
```

Check the individual folders for the implementation you want to run.
